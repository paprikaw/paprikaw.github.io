# Xu Bai's personal website

Live website: https://paprikaw.github.io/

Static HTML version of [Minimal Light](https://github.com/yaoyao-liu/minimal-light), adapted for Xu Bai. The theme's CC0 license is preserved in `THEME-LICENSE`.

## Editing

- `index.html`: biography, publications, education, teaching, and experience.
- `assets/css/site.css`: site-specific styles.
- `assets/img/avatar.svg`: initials avatar; replace with a profile photo when available.
- `assets/bib/`: arXiv BibTeX entries.

Serve locally with `python3 -m http.server 8765`. GitHub Pages publishes `main` from the repository root. No build step is required.

Publication titles and author lists were checked against arXiv on 2026-10-07. Conference status follows the supplied CV. PixelFlow is listed as a preprint. BibTeX files describe arXiv versions rather than conference proceedings.
